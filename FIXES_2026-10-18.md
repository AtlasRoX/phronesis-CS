## 3. Run-analysis report: latency and bounded work

| Issue | Fix | Files |
|---|---|---|
| The budget ran out before the run finished | A token and call reserve for the final answer and verification (12% of the budget, minimum 20k, at most 30%). A call reserves its prompt plus its output up front, so parallel calls cannot overshoot together. | `phronesis/agentic/budget.py`, `phronesis/agentic/llm.py`, `phronesis/agentic/topologies.py` (debate critics only run when they fit) |

| Repeated FDA-gap searches and rewrites | A new result counts only if it is relevant to its gap. Off-topic web results don't trigger a rewrite. Near-duplicate queries are skipped (Jaccard ≥ 0.6). A gap is retired after a search with no usable result. Hedged sentences already searched aren't searched again. The gap prompt lists earlier queries. The gap report records novelty counts. | `phronesis/agentic/gaps.py` |

## Not finished

- **Rewrites still regenerate the whole answer.** They are told to keep unchanged text verbatim and now happen far less often. True section-level patching would need a bigger redesign.
- **Cancel inside agent JSON calls** (planner, critics) waits for the call to return. The draft, rewrites and verifier revision are cancellable.
- **openFDA checks at most 3 candidate drugs per target.** ChEMBL describes KRAS drugs only as "KRas inhibitor", so the answer notes when allele specificity can't be confirmed.
- **Per-claim version IDs and resumable checkpoints** (suggested in the report) are not implemented.
- **Live benchmark still needed:** run the same KRAS G12C brief on Auto and on Plan & Execute at the same effort level and compare time, tokens, rewrites and verification results.
