    Configuration reference

    Every environment variable read by phronesis/ and app/ (tests excluded). Types, defaults and descriptions come from the settings registry (phronesis/config/settings.py); the "Read at" column comes from scanning the code. Regenerate with python scripts/gen_env_reference.py; CI can run it with --check, which also fails when a variable read in the code is not registered. A commented template is in .env.example.

    At startup the API validates the environment (phronesis.config.validate_environment): unparsable or out-of-range numbers, unknown choices, non-boolean flags and PHRONESIS_* names that no code reads (likely typos) are logged as warnings, counted in config_problems on /api/health, and fail startup only with PHRONESIS_STRICT_CONFIG=1. Invalid values fall back to the default.

    Precedence for state directories: a specific variable (PHRONESIS_MEMORY_DIR, PHRONESIS_RUNS_DIR, PHRONESIS_UPLOAD_ROOT, PHRONESIS_JOBS_DIR, PHRONESIS_TOOL_CACHE_DIR) wins over PHRONESIS_DATA_DIR; with neither set, every store keeps its historical location under the workspace.
